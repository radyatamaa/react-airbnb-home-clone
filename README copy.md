# Airbnb Host Homes - UI Clone (React)

This is a UI-only implementation inspired by the provided desktop + mobile screenshots.
- React (Vite)
- Dummy JSON data (no database)
- Unit tests with Vitest + React Testing Library

## Run locally

```bash
npm install
npm run dev
```

## Run tests

```bash
npm test
```

## Notes
- Focus is on layout, spacing, and responsive behavior.
- Images are mocked with lightweight UI placeholders (phone frames, widgets).
- Accordion is interactive; hero estimate number changes using dummy logic.
